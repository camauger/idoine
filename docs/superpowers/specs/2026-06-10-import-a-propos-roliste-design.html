Contexte

Le chantier initial visait à « importer les articles et pages de C:\dev\ludomancien2024 » (ancien site Vue/Vite) dans ce repo (générateur Idoine). L'exploration a montré que l'essentiel est déjà importé :

  • 33 articles : corps de texte strictement identiques entre les deux repos ; seul le front matter a été normalisé côté Idoine (clés triées, ajout de title/summary).
  • Images : les ~145 images d'articles (banners, thumbnails) sont déjà dans src/assets/images.

Restaient quatre contenus non importés ; après arbitrage, un seul est retenu :

Objectif

Remplacer le contenu actuel de la page « À propos » (portfolio professionnel) par le récit rôliste personnel de ludomancien2024, en FR et en EN, et nettoyer le SCSS portfolio devenu orphelin.

Décisions validées

  • Remplacement complet — le contenu portfolio est retiré (pas de fusion).
  • Repères temporels actualisés à 2026 — chaque ajustement est soumis dans le diff.
  • Approche B — réécriture Markdown pur + nettoyage SCSS orphelin.
  • Version EN traduite — traduction fidèle du récit, mêmes repères actualisés.
Conception

1. Contenu FR — src/locales/fr/pages/about.md

  • Corps actuel (HTML portfolio : .intro, .passion-card, .expertise-grid, etc.) remplacé par le récit rôliste de a-propos.vue, converti en Markdown pur : paragraphes simples, aucun balisage HTML.
  • Front matter conservé : title, slug: a-propos, template: pages/about.html, translation_id: about.
  • description (SEO) réécrite pour refléter le récit rôliste.
  • Actualisation des repères temporels (texte écrit vers 2021) : « cela fait 30 ans » → ajusté (initiation fin des années 80, donc « près de 40 ans » ou équivalent) ; « au Québec depuis 20 ans » → « depuis 25 ans » ; tout autre repère daté détecté est listé dans le diff.
  • La voix et le contenu du texte sont préservés ; pas de réécriture stylistique.

2. Contenu EN — src/locales/en/pages/about.md

  • Traduction fidèle du même récit (voix personnelle préservée, repères actualisés identiques).
  • Même structure de front matter que la page FR (avec translation_id: about).

3. Nettoyage SCSS — src/styles/pages/_about-page.scss

  • Les classes portfolio (.intro, .section-title, .passion-card, .expertise*, .impact*, .games, .contact*, .card-title…) ne sont utilisées que par les deux about.md → supprimables après réécriture.
  • .container est aussi utilisé par src/templates/pages/glossary.html → la règle est déplacée vers un emplacement partagé (layout/base) ou conservée ; elle ne doit pas disparaître.
  • La règle globale body { … } est probablement redondante avec les styles de base → vérifier avant suppression ; en cas de doute, la conserver.
  • Le @use "about-page" dans src/styles/pages/index.scss est retiré ou ajusté selon ce qui reste.
⚠️ _about-page.scss contient des règles génériques (body, .container) : ne pas supprimer le fichier en bloc sans avoir traité ces deux cas.

4. Vérification

  • Build local : python scripts/build.py sans erreur.
  • Contrôle visuel : pages /a-propos (FR), /en/about (EN) et glossaire (pour .container).
  • Aucun autre template ni page ne doit changer.
