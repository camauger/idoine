1. SESSION AUTOMNE 2026 (contenu)
--------------------------------------------------------------------------------

- La section « début des cours » ne mentionne plus la session d'été
  (2 juillet) : elle affiche désormais la Session Automne 2026 —
  début le 14 septembre, durée 8 à 10 semaines, inscriptions à partir
  du 3 août.

  src/config/site_config.yaml (bloc « session ») : une seule place à
  modifier à chaque changement de session. La page /cours et la pastille
  du formulaire d'inscription lisent toutes deux ces variables.

Fichiers : src/config/site_config.yaml, src/templates/pages/cours.html,
src/templates/pages/inscription.html, src/locales/fr/pages/cours.md

2. FORMULAIRE D'INSCRIPTION
--------------------------------------------------------------------------------

a) Nouvelle question « Je désire utiliser ma propre argile » (radio Oui/Non) :
   - Oui (35$ déduits de l'inscription) / Non (prix régulier).
   - Visible uniquement pour les cours de céramique (affichage géré par
     src/scripts/formPrefill.js selon la discipline du cours choisi).

b) Notes importantes simplifiées :
   - Retrait des mentions de coût d'argile et de matériel vitrail.
   - Conservé : « Cuissons en sus pour les cours de céramique » et la
     carte de membre obligatoire.

c) Mode « Demande d'information » quand aucun cours n'est disponible :
   - Avant : « Erreur de chargement... » et formulaire bloqué.
   - Maintenant : le sélecteur propose « Demande d'information », le
     récapitulatif explique la situation, et le formulaire reste
     utilisable pour une demande générale (le bouton devient
     « Envoyer ma demande d'information »).

d) Corrections d'alignement :
   - Champs de formulaire alignés en bas de leur rangée quand une
     étiquette passe sur deux lignes (section « Personnes à inscrire »).
   - Carte « Vous préférez nous écrire directement ? » : texte aligné à
     gauche à côté de l'icône, espacement augmenté.

Fichiers : src/templates/pages/inscription.html, src/scripts/formPrefill.js,
src/styles/components/_forms.scss, src/styles/pages/_inscription.scss

8. PASSE SEO TECHNIQUE
--------------------------------------------------------------------------------

a) Balises on-page (toutes les pages, via head.html) :
   - Canonical absolu avec slash final (ex. https://atelierstelme.ca/a-propos/).
   - Open Graph : og:type, og:site_name, og:locale (fr_CA), og:title,
     og:description, og:url, og:image (+ twitter:card).
   - Image de partage par défaut : hero-workshop.jpg (clé
     default_og_image dans site_config.yaml ; hero_image de la page en
     priorité si défini).
   - Balise noindex conditionnelle pilotée par le frontmatter
     (noindex: true) — active sur /admin, /inscription-merci,
     /contact-merci.

b) Sitemap et robots.txt générés à chaque build :
   - Scripts autonomes dans scripts/seo/ (sans dépendance npm).
   - sitemap.xml : 11 URLs publiques, les routes noindexées sont exclues.
   - robots.txt : tout autorisé + déclaration du sitemap. Pas de
     Disallow sur /admin : le noindex doit rester visible des robots.
   - Commandes : npm run sitemap / robots / verify-seo / seo.
   - npm run build et le build Netlify (netlify.toml) enchaînent
     automatiquement la génération SEO (le build Python nettoie dist,
     les fichiers doivent être régénérés après chaque build).
   - L'URL de production est passée explicitement
     (--url https://atelierstelme.ca) car le .env local contient
     SITE_URL=http://localhost:9000 qui faussait l'auto-détection.

c) Vérification : npm run verify-seo passe au vert (fichiers présents,
   sitemap valide, toutes les pages ont title, description, canonical
   et Open Graph).

d) À FAIRE APRÈS DÉPLOIEMENT :
   - Soumettre https://atelierstelme.ca/sitemap.xml dans Google Search
     Console et Bing Webmaster Tools (le ping automatique n'existe plus
     depuis 2023).
   - Valider l'aperçu de partage avec les débogueurs Facebook/Twitter.

Fichiers : src/templates/components/head.html, src/config/site_config.yaml,
scripts/seo/ (4 scripts), package.json, netlify.toml,
src/locales/fr/pages/{admin,inscription-merci,contact-merci}.md
